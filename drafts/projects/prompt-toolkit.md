## 问题

提示词散落在代码各处，改一句要重新部署；改完到底变好还是变差，全靠感觉。

这个工具把提示词抽出来单独管理。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| 版本管理 | 每次修改留档，可回滚、可对比 |
| 变量与模板 | 提示词与业务数据解耦，同一份模板多处复用 |
| 回归测试 | 一组固定输入 + 期望判定，改动后自动跑 |
| 灰度发布 | 按比例把流量切到新版本，对比指标 |

## 回归测试怎么判定

自由文本没有唯一正确答案，所以判定方式要做成可插拔的：

- 包含 / 不包含某些关键词
- 正则匹配
- 结构化输出（JSON）的字段校验
- 调用另一个模型做打分

多数场景下前三种就够用了，第四种成本和不确定性都更高。

## 与代码的关系

提示词有独立版本号，代码里只引用标识符：

```ts
const answer = await prompt.run('qa.answer', {
  version: '3',
  variables: { context, question },
});
```

切换版本不需要改代码、不需要重新部署。
