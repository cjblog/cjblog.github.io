## 他解决什么问题

内部文档散落在网盘、Confluence、共享盘里，找一句话要翻半天。
这套系统把这些文档统一索引，用自然语言就能问到答案，并给出出处。

## 与通用问答的区别

- **权限过滤**：检索前先按用户所在部门过滤文档，避免越权读到不该看的内容
- **答案溯源**：每条回答都附原文片段，可以点开核对
- **私有化部署**：全部组件可离线运行，数据不出内网

## 架构

```text
用户提问
   │
   ├─ 权限过滤 ──> 候选文档集
   │
   ├─ 混合检索 ──> Top-K 文档块
   │
   ├─ 重排序   ──> 精选上下文
   │
   └─ 生成     ──> 答案 + 引用
```
