## 这是什么

一份边做边记的建站笔记。左边是全书目录，右边是当前这一章的标题目录。

## 适合谁看

写过一点前端、想把内容站搭起来但不想引入一整套框架的人。所有代码都是静态构建，不依赖服务端。

## 全书结构

- **入门** —— 为什么选它、第一个页面
- **内容与集合** —— Markdown 与 frontmatter、图片与静态资源
- **部署** —— 构建产物与托管

## 约定

书里的代码都基于 Astro 7。大版本之间 API 有变动，遇到不一致时以你本地安装的版本为准，不要照抄记忆里的写法。
