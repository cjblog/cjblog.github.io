## 简介

调试 Agent 最麻烦的地方是它不透明：一次失败到底是规划错了、工具选错了，还是观察结果理解错了，从最终输出上看不出来。

这个实验台把循环的每一步都记录下来，并提供可视化的执行轨迹。

## 结构

```text
观察 → 规划 → 行动 → 反思 → （回到观察）
```

每一步都可以替换实现，方便做消融对比。

## 可观测性

| 记录项 | 用途 |
| --- | --- |
| 每步的输入输出 | 定位是哪一步开始跑偏 |
| 工具调用参数 | 检查是不是参数传错 |
| 检索到的上下文 | 判断是否因为上下文缺失 |

## 已实现的能力

- 工具注册与参数校验
- 中断与恢复（把状态存 Redis，进程重启不丢）
- 同一任务用不同策略重放，直接对比轨迹
